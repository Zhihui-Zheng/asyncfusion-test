# Fusion5 时序稳定训练说明（Anchor Residual Loss）

## 1. 要解决的问题

当前现象是：
- 静态区域融合效果好；
- 动态区域容易出现伪影（抖动、拖影、局部漂移）。

根因通常不是“没有时序模块”，而是**训练目标把重点放在整帧回归**，导致模型在动态区更容易累计误差。

---

## 2. 参考依据（参考什么）

本方案参考 Cinemo 的核心思想（不是照搬结构）：

> 把学习目标从“直接生成帧”改为“生成相对锚帧的运动残差”，再用标准扩散/速度监督训练。

对 Fusion5 的映射是：
- 保留你当前 Flow Matching 框架；
- 将监督变量改到残差空间；
- 继续冻结 ControlNet，重点训练 U-Net。

---

## 3. GT 如何构造（依据什么）

你有每帧 GT，因此**不需要光流制作 GT**。

设：
- `Z_vi`：VI latent，形状 `(B,C,T,H,W)`
- `Z_gt`：融合 GT latent，形状 `(B,C,T,H,W)`
- `a`：锚帧索引（建议用现有 `ir_anchor_idx`）
- `Z_anchor = Z_vi[:,:,a:a+1]`

定义锚帧残差：
- `M_vi = Z_vi - Z_anchor`
- `M_gt = Z_gt - Z_anchor`

说明：
- 残差是相对锚帧（VI 锚帧），不是相对 IR；
- GT 只用于监督 `M_gt`，无需额外光流 GT。

---

## 4. Loss 原理（依据的是哪一个 loss）

## 4.1 主损失：残差空间速度监督（核心）

在 Flow Matching 中：
- `M_t = (1-t) * M_vi + t * M_gt`
- 目标速度 `U* = M_gt - M_vi`
- 网络预测 `U_theta`

主损失：
- `L_vel = ||U_theta - U*||^2`

这等价于“标准速度 MSE”，但变量从绝对帧换成了锚帧残差。

## 4.2 重建一致性损失（建议）

把预测残差加回锚帧：
- `Z_hat = Z_anchor + M_hat`

低频一致性：
- `L_rec = ||LPF(Z_hat) - LPF(Z_gt)||_1`

作用：约束结构与外观稳定，减少低频漂移。

## 4.3 残差时间差分损失（建议）

- `L_dt = ||(M_hat_t - M_hat_{t-1}) - (M_gt_t - M_gt_{t-1})||_1`

作用：直接约束“运动轨迹形状”，比单步 `pred_next/gt_next` 更有时序约束价值。

## 4.4 总损失

- `L_total = L_vel + λ1 * L_rec + λ2 * L_dt`

建议起始权重：
- `λ1 = 0.05 ~ 0.2`
- `λ2 = 0.05 ~ 0.15`

---

## 5. 一句话原理 + 一句话好处

- 原理一句话：**用“相对锚帧的运动残差”替代“整帧绝对值”做监督，训练目标仍是标准 MSE/速度监督。**
- 好处一句话：**把静态外观锁在锚帧上，模型主要学习“怎么动”，从而降低动态伪影和时序漂移。**

---

## 6. 为什么先冻结 ControlNet

建议阶段一保持：
- ControlNet 冻结；
- 重点训练 U-Net（空间分支 + 残差建模相关路径）。

理由：
- 你的条件输入分布（IR 复制多帧）已经稳定；
- 当前主要问题在动态建模，不在条件编码器；
- 先减少变量，定位 loss 是否有效更快更稳。

可选阶段二：
- 若仍有残余伪影，再小学习率解冻 ControlNet 后层微调。

---

## 7. 与当前实现的关系（关键提醒）

当前 `pred_next = x_t + dt * pred_velocity` 的时序项，和 `L_vel` 高度相关，新增约束有限。  
采用本说明的锚帧残差损失后，时序约束会更直接地作用在“运动变化量”上，而不是重复惩罚同一误差来源。

---

## 8. 最小落地顺序（建议）

1. 保持现有数据管线与冻结策略不变；
2. 引入 `Z_anchor`、`M_vi`、`M_gt`；
3. 将主监督迁移到残差空间 `L_vel`；
4. 增加 `L_rec` 与 `L_dt`；
5. 先用小权重训练并观察动态伪影变化。
